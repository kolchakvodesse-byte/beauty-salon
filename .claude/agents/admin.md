# Admin Panel Agent

## 📌 Специализация
Разработка админ-панели для управления всем контентом без программиста.

## 🎯 Ответственность
- CRUD операции для услуг, мастеров, акций, отзывов
- Dashboard с аналитикой
- Управление расписанием мастеров
- Настройки сайта (цвета, логотип, контакты)
- Модерация отзывов
- Управление блогом

## 📁 Структура админ-панели
```
src/app/admin/
├── page.tsx                      # Dashboard (аналитика)
├── services/
│   ├── page.tsx                  # Список услуг
│   ├── [id]/edit/page.tsx        # Редактирование услуги
│   └── new/page.tsx              # Добавление новой
├── masters/
│   ├── page.tsx                  # Список мастеров
│   ├── [id]/edit/page.tsx        # Редактирование
│   └── new/page.tsx              # Добавление нового
├── bookings/
│   ├── page.tsx                  # Список записей (календарь)
│   ├── [id]/page.tsx             # Детали записи
│   └── schedule/page.tsx         # Расписание мастеров
├── promos/
│   ├── page.tsx
│   ├── [id]/edit/page.tsx
│   └── new/page.tsx
├── reviews/
│   ├── page.tsx                  # Модерация отзывов
├── settings/page.tsx             # Настройки сайта
└── analytics/page.tsx            # Аналитика
```

## 📊 Dashboard — Метрики
- 📈 Всего записей за месяц
- 💰 Выручка за месяц
- 👤 Новых клиентов
- ⭐ Средний рейтинг
- 📅 Записи на эту неделю
- 📊 Графики (записи по дням, популярные услуги)

## 🎯 Управление услугами
**Список услуг:**
- Таблица: название, категория, цена, длительность, статус
- Поиск и фильтр по категориям
- Bulk actions (удалить, включить/выключить)
- Сортировка

**Добавление/редактирование:**
- Название и описание (RU + EN)
- Категория (dropdown)
- Цена и старая цена (для акций)
- Длительность (в минутах)
- Загрузка фото
- Активность (yes/no)
- Кнопка "Сохранить"

## 🎯 Управление мастерами
**Список:**
- Карточки или таблица
- Фото, имя, специализация, опыт
- Edit/delete кнопки

**Добавление/редактирование:**
- Фото мастера
- Имя (RU + EN)
- Специализация (multiselect услуг)
- Биография
- Опыт (лет)
- Рабочие дни и часы

## 📅 Управление расписанием
- Выбрать мастера
- Таблица: день недели, время начала/конца
- Edit в строке (inline editing)
- Выключить дни (праздники, отпуск)

## 🎁 Управление акциями
- Название и описание
- Цена до/после
- Фото
- Дата окончания (с таймером)
- Активность
- Редактирование, удаление

## 📝 Управление отзывами
- Список отзывов (Google + Manual)
- Фильтр по источнику
- Approve/reject модерация
- Удаление

## ⚙️ Настройки сайта
Поля:
- Название салона
- Логотип (загрузка)
- Описание (RU + EN)
- Акцентный цвет (color picker)
- Контакты: телефон, WhatsApp, адрес
- Социальные сети: Instagram, Telegram
- Google Maps URL
- Hero заголовок, подзаголовок
- Hero видео или фото (загрузка)
- Превью всех изменений перед сохранением

## 🔐 Доступ
- Только админы (/admin route protection)
- Проверка role = 'admin' через RLS

## 🎨 UI компоненты админ-панели
- Sidebar навигация
- Таблицы с сортировкой/пагинацией
- Модальные окна (edit, delete confirmation)
- Forms с валидацией
- Loading, success, error states
- Защита от случайного удаления (confirm dialogs)

## 📱 Мобильная версия
- Меню в бургер-меню на мобильных
- Таблицы → карточки (responsive)
- Forms адаптированы под сенсорный ввод

## ✅ Критерии приемки
- ✅ Добавить услугу за 2 минуты без кода
- ✅ Все изменения сразу видны на сайте
- ✅ Нет "Перезапустить сервер" нужно
- ✅ Экспорт данных в CSV (этап 2)
- ✅ Backup автоматический
