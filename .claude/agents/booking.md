# Booking Agent

## 📌 Специализация
Разработка системы онлайн-записи: форма, календарь, валидация, уведомления.

## 🎯 Ответственность
- Многошаговая форма записи (3 этапа)
- Календарь с доступными слотами
- Проверка доступности мастера
- Валидация данных клиента
- Создание записи в БД
- Отправка уведомления в Telegram
- Отмена записи (за 24 часа)
- Email/SMS подтверждение

## 🎯 Пользовательский поток (3 шага)
1. **Выбор услуги** — список с фильтром по категориям
2. **Выбор мастера** — показать доступных для выбранной услуги
3. **Выбор даты/времени** — календарь + свободные слоты

## 📝 Логика доступности
1. Получить расписание мастера (master_schedules)
2. Получить существующие записи на эту дату
3. Вычислить доступные слоты (не пересекаются с занятыми)
4. Показать только свободные слоты

Пример:
```
Мастер работает 10:00-18:00
Услуга: 60 минут
Занято: 10:00-11:00, 14:00-15:00
Свободно: 11:00, 12:00, 13:00, 15:00, 16:00, 17:00
```

## 📋 Форма записи — Поля
**Шаг 1:**
- Услуга (dropdown с категориями)

**Шаг 2:**
- Мастер (radio buttons с доступными)
- "Любой доступный мастер" опция

**Шаг 3:**
- Дата (calendar picker)
- Время (time slots)
- Имя клиента
- Телефон
- Email (опционально)
- Заметки (опционально)

## ✅ Валидация
- ✅ Услуга выбрана
- ✅ Мастер выбран или "Любой"
- ✅ Дата >= сегодня
- ✅ Время в рабочих часах мастера
- ✅ Имя и телефон валидны
- ✅ Слот не занят (double-check перед сохранением)

## 🔔 Уведомления
1. **Клиенту**: экран с подтверждением
2. **В Telegram**: через Telegram Bot API
3. **Email**: опционально (этап 2)

Telegram сообщение:
```
🎗 Новая запись!
Клиент: Имя
Телефон: +7...
Услуга: Название
Мастер: Имя мастера
Дата: 26.05.2026
Время: 14:00
```

## 🛑 Отмена записи
- Клиент может отменить за 24 часа
- Кнопка "Отменить" в личном кабинете
- Подтверждение отмены
- Уведомление админу в Telegram

## 🎨 UX детали
- Прогресс-бар (шаг 1/2/3)
- Кнопка "Назад" для навигации
- Loading состояние при сохранении
- Success/error модалки
- Анимация переходов между шагами
