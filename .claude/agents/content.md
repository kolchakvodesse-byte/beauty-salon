# Content Agent

## 📌 Специализация
Работа с контентом: услуги, мастера, отзывы, блог, портфолио, FAQ.

## 🎯 Ответственность
- Создание и управление услугами + категориями
- Профили мастеров и их портфолио
- Отзывы клиентов (Google Reviews + ручные)
- Blog статьи и SEO
- FAQ аккордеон
- До/После галерея (портфолио)
- Акции и промоции
- Image optimization и хранение

## 📁 Компоненты и страницы
```
src/
├── app/(public)/
│   ├── services/page.tsx           # Каталог услуг
│   ├── services/[slug]/page.tsx    # Детали услуги
│   ├── masters/page.tsx            # Список мастеров
│   ├── masters/[id]/page.tsx       # Профиль мастера
│   ├── portfolio/page.tsx          # До/После галерея
│   ├── promo/page.tsx              # Акции

```

## 🛍️ Управление услугами
**Категории:**
- Таблица в админ-панели: название, icon, сортировка, активность
- RU + EN поддержка
- Встроенные иконки (face, body, hair, nails)

**Услуги:**
- Название + описание (RU + EN)
- Категория (dropdown)
- Цена + старая цена (если скидка)
- Длительность (минуты)
- Фото (оптимизированная, webp)
- Featured услуги (популярные)
- Сортировка в категории
- Активность on/off

**Фильтры на /services:**
- По категориям
- По цене (range slider)
- Поиск по названию

## 👥 Управление мастерами
**Информация:**
- Фото (аватар)
- Имя + биография (RU + EN)
- Роль/специализация
- Опыт (лет)
- Сертификаты (текст)
- Социальные сети (опционально)

**Портфолио мастера:**
- Галерея "до/после"
- Каждое фото с описанием
- Связь с услугой (какая услуга на фото)

**На странице /masters:**
- Карточки мастеров (фото, имя, специализация)
- Клик → профиль с биографией и галереей
- "Записаться к этому мастеру" кнопка

## 📸 До/После портфолио
**Таблица portfolio:**
- 2 фото (до/после)
- Описание процедуры
- Связь с мастером и услугой
- Активность

**Страница /portfolio:**
- Слайдер или grid с сравнением
- Hover → показывает описание
- Фильтр по услугам и мастерам

## ⭐ Отзывы
**Источники:**
1. Google Reviews (синхронизация через API)
2. Ручные отзывы (админ добавляет в админ-панель)

**Информация в отзыве:**
- Имя клиента
- Рейтинг (1-5 звезд)
- Текст отзыва
- Фото (опционально)
- Услуга / мастер (если известно)
- Дата

**На странице /reviews:**
- Карточки отзывов
- Фильтр по рейтингу
- Средний рейтинг вверху
- Sorting (новые, популярные, high-rated)

## 📝 Blog
**Статья содержит:**
- Заголовок (RU + EN)
- Slug (для URL)
- Cover фото
- Excerpt (краткое описание)
- Content (markdown или rich text)
- Author
- Дата публикации
- SEO: meta description, keywords

**На /blog:**
- Список статей (карточки + превью)
- Пагинация или infinite scroll
- Search по названию
- Category tags (опционально)

**На /blog/[slug]:**
- Полный текст статьи
- "Related posts" внизу
- Share в социальные сети

## ❓ FAQ
**Структура:**
- Вопрос (RU + EN)
- Ответ (RU + EN)
- Сортировка
- Активность

**На /faq:**
- Аккордеон (collapse/expand)
- Поиск по вопросам
- Категории (опционально)

## 🎁 Промоции
**Информация:**
- Название (RU + EN)
- Описание
- Цена старая / новая
- Фото
- Дата окончания (таймер)
- Активность

**На /promo:**
- Карточки с таймерами
- Кнопка "Записаться" в акцию
- Auto-hide истёкшие

## 📸 Image Management
- Загрузка в Supabase Storage (/images)
- Оптимизация (WebP, resize)
- CDN кэширование
- Плейсхолдеры (skeleton loading)

## 🌐 Мультиязычность
- RU / EN для всех текстов
- Language selector в header
- URL структура: /services vs /en/services (или query param)
- i18n middleware

## 📊 SEO
- Meta tags на каждой странице
- Open Graph для шаринга
- Sitemap.xml
- robots.txt
- Структурированные данные (schema.org)
